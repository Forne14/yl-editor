# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/Forne14/yl-editor/security/advisories/new), not in a public issue or
pull request.

Include the affected tag or commit, what an attacker can do, and the steps to reproduce it. You should hear back
within a week. Fixes ship as a new tag; the advisory names the first tag that contains the fix.

Only the latest tag is supported.
